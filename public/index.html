Backend authentication is not configured

Static demo mode has no authentication server, so Admin login cannot verify credentials securely on the frontend. To enable real Admin access:

  1. Set SUPABASE_URL and SUPABASE_ANON_KEY in .env or Vercel environment variables.
  2. Apply the database migrations in supabase/migrations/ (including RLS role policies).
  3. Create the initial admin account in Supabase Auth (Email/Password) and promote it via SQL:
    UPDATE public.profiles SET role = 'admin', status = 'active' WHERE email = '<admin-email>';

Public admin registration is disabled. New admins must be provisioned by an existing administrator or database SQL.
